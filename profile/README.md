# Twin Cities Open Systems (TCOS)

Welcome to the centralized entry point and architecture index for **Twin-Cities-Open-Systems**. We engineer open, automated, multi-agent frameworks, trading thesis simulation platforms, and bare-metal environments.

## ⚖️ Core Operational Philosophy: Public by Default
Our organization operates under a strict **Public by Default** engineering standard. We believe transparency drives architectural resilience and programmatic integrity. 

* **Open Infrastructure:** All core systems, developer tooling layouts, and research frameworks are public or are built with a direct migration timeline to become public.
* **Protected Primitives:** Repositories containing sensitive individual credentials, private resource scheduling configurations, or proprietary core computational IP remain strictly isolated to safeguard the platform's execution core.
